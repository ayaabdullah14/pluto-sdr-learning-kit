# المثال 8: تسجيل القياسات

**افتحي:** `ex08_tx_beacon.grc وex08_rx_logger.grc` من مجلد `flowgraphs` بواسطة File → Open في GNU Radio Companion، ثم Generate وExecute.

طبّقي إعدادات الأجهزة وشروط المختبر كما في README قبل التشغيل.

**شو تلاحظي؟** طيف ورقم قدرة فقط، بينما تُحفظ القياسات في CSV.

**مهمتك الآن:** اختاري مسار log_file واسم run_label، ثم اجمعي baseline وTX-on بإعدادات متطابقة؛ الوقت هو وقت معالجة الكمبيوتر.

**كيف يفيدك بالمشروع؟** يساعدك تفهمي وتتحققي من مرحلة في مسار إشارة الروبوت؛ انتقلي للمثال التالي بعد تحقيق Completion criteria الموجود في README.

- `README.md`: اتّبعيه أثناء العمل، وفيه خطوات القياس وتشخيص الأخطاء.
- `REPORT.md`: السبب العلمي، المعادلات وقرارات التصميم.
- الصور التي تحمل اسم layout هي دليل للدائرة. صور reference هي محاكاة مرجعية، وليست نتائج من جهازيك.

خذي خطوة واحدة كل مرة. المطلوب أن تتوقعي النتيجة ثم تفسري ما حدث، وليس فقط أن تضغطي Run. إذا ظهر خطأ، سجّلي أول رسالة خطأ كما هي بدل تغيير عدة إعدادات معًا.
